*Programming Techniques*
- Dynamic Programming
    - i.e. breaking down a problem into smaller / simpler subproblems
    - i.e. bottom-up problem solving
- Right-Left Pointers
    - if there is order to the list O(n^2) chained loops can sometimes be reduced to O(n) complexity
- Efficient prime sieves
- Memoization  (Space-Time Tradeoff)

*Combinatorial Optimization*
- Knapsack problem and its unbounded variant
    - e.g.    15kg knapsack, highest value combination of items not exceeding the 15kg weight limit

*Number Theory*
- Diophantine equations
- Extended Euler Algorithm for gcd and Bézouts identity ax + by = gcd(a, b)
- Legendre's Formula
    - gives the largest power of a prime that divides a factorial

*Numerics*
- Lagrangian Interpolation

*Graph Theory*
- Incidence Matrix
- Adjacency Matrix
- Minimum Spanning Trees
    - Prims Algorithm

*Heaps*
- Min-Heap
    - finding the minimal elem is O(1)
    - popping the minimal elem is O(log n),  where n is the total amount of elems in the heap
    - pushing a new elem is O(log n)
